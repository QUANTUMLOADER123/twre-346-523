# strafe.zone — свой «CS» с чит-меню

Браузерный 3D-шутер на three.js: движение как в Source/CS:GO, боты, 4 карты и встроенное чит-меню на **Insert**
(rage/legit-аим, антиаимы с крутилкой и десинком, фейклаги, бхоп, автострейф, ESP, чамсы и т.д.).
Все читы — только против ботов в твоей собственной игре.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
# или продакшн-сборка
npm run build && npm run preview
```

Лучше играть в отдельной вкладке браузера: внутри iframe захват мыши (pointer lock) может быть недоступен.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Space / колесо мыши | прыжок |
| C / Ctrl | присесть |
| Shift | идти тихо |
| ЛКМ / ПКМ | огонь / прицел (снайперки), вторая атака ножом |
| R | перезарядка |
| 1 / 2 / 3, Q | оружие, последнее оружие |
| F | осмотр оружия |
| B | меню покупки (1–4 — AK-47, M4A4, AWP, SSG 08) |
| Tab | таблица счёта |
| **Insert** (или Home) | **чит-меню** |
| V | вид от третьего лица |
| X | инверт десинка |
| ← → ↓ / ↑ | ручной антиаим (лево / право / назад) / сброс |
| T | рестарт KZ-таймера (bhop_lava) |
| Esc | пауза |

## Карты

- **de_dust** — песчаная карта с длинной, мидом и двумя «плентами», TDM.
- **de_warehouse** — склад с контейнерами, ящиками и проходами, TDM.
- **aim_redline** — компактная aim-карта с укрытиями для перестрелок.
- **bhop_lava** — KZ/бхоп-карта над лавой: таймер, чекпоинты, лучшее время, джамп-статы.

## Движение (как в Source)

64 тика, юниты Source: `sv_accelerate 5.5`, `sv_friction 5.2`, `sv_stopspeed 80`, `sv_airaccelerate 12`,
скорость бега 250 (зависит от оружия), прыжок ~57 юнитов, разгон через стрейфы в воздухе, приседание в прыжке,
стрейф без мгновенной смены направления. Бхоп без читов возможен (с правильным таймингом), с `Bunny hop` — автоматически.

## Чит-меню (Insert)

- **Rage**: аимбот с выбором хитбоксов, хитшанс, мин. урон, silent aim, autofire/autoscope/autostop, doubletap.
- **Anti-Aim**: pitch (Down/Up/Zero/Jitter), yaw (Backward/Spin — крутилка/Jitter/Sideways…), at targets,
  десинк (Static/Jitter) c настройкой body yaw, LBY-break, ручной AA, инверт.
- **Fake lag**: Static/Adaptive/Random, лимит до 14 тиков, разжатие при выстреле. Боты стреляют по «серверной»
  модели, поэтому десинк и фейклаги реально влияют на попадания (видно фейк-чамсами в 3-м лице).
- **Legit**: аимбот с FOV и сглаживанием, RCS, триггербот.
- **Visuals**: ESP (боксы, имя, HP, оружие, скелет, снаплайны, стрелки за экраном), чамсы (Flat/Shaded/Metallic/Glow/Wireframe,
  сквозь стены), локальные/фейк-чамсы, радар, найтмод, asus walls, FOV/viewmodel, 3-е лицо, трейсеры, хитмаркеры,
  индикатор скорости, кейстроки, график скорости, джамп-статы.
- **Misc**: bhop, автострейф (Legit/Directional/Rage), edge jump, quick stop, no recoil/no spread, sv_airaccelerate,
  хитсаунды, бесконечные патроны, godmode, killsay.
- **Skins**: скины для оружия и ножа. **Config**: слоты конфигов, экспорт/импорт.

## Проверка без браузера

```bash
node tools/simtest.mjs    # компиляция карт, навигация, физика движения
node tools/headless.mjs   # симуляция матчей с ботами (с читами и без)
node tools/apptest.mjs    # весь App с фейковым DOM/рендером — ловит ошибки рантайма
node tools/bhoptest.mjs   # бхоп/автострейф на bhop_lava
```
